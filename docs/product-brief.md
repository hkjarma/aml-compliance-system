# AML Product Brief

## Problem
Financial institutions require real-time surveillance to identify suspicious financial activity, prevent illicit transfers, and maintain compliance with AML regulations.

## Target users
- AML investigators
- Compliance managers
- Risk analysts
- Operations teams
- Auditors and regulators

## MVP capabilities
1. Monitor transaction flows and score them for risk
2. Detect common suspicious patterns such as structuring, rapid movement, high-risk countries, and payments to sanctioned or unusual counterparties
3. Generate alerts and case records for investigation
4. Expose a dashboard and API for downstream integration

## Data model
- Customer / account profile
- Transactions and payment events
- Counterparties and geographies
- Risk scores and rule hits
- Cases and investigation actions

## Success metrics
- alert precision and analyst review time
- time-to-detect suspicious events
- case closure rate
- auditability and evidence retention

## Recommended next steps
- add KYC and sanctions integration
- enrich with network analytics
- add explainable model review and thresholds tuning
- build reporting and suspicious activity filing tooling
